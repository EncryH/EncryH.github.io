# 1. K-Shield 주니어란?

KISA(한국인터넷진흥원)에서 운영하는 정보보안 인력 양성 프로그램이다. 기초과정과 심화과정으로 나뉘는데, 나는 **기초과정**을 수료했다.

| 항목 | 내용 |
|------|------|
| 과정명 | K-Shield 주니어 기초과정 |
| 주관 | KISA (한국인터넷진흥원) |
| 기간 | 2026.07.01 ~ 2026.07.31 (80시간) |
| 수료증 번호 | No.2026-k_shield Jr(Basic course)-000243 |

정보보안공학과를 다니면서 학교 수업에서 배우는 이론은 있는데, 실무 쪽으로 한 번 체계적으로 정리해보고 싶었다. 마침 K-Shield 주니어 모집 공고를 보고 바로 신청했다. 

# 2. 커리큘럼 구조

전체 커리큘럼은 크게 4개 파트로 구성되어 있다.

```
K-Shield Jr 기초과정
├── 01. 리눅스 운영체제 기초
├── 02. 윈도우 운영체제 기초
├── 03. 네트워크 기초
└── 04. 정보보안 기본요소 이해하기
```

운영체제 두 개를 먼저 잡고, 네트워크를 다진 다음에 보안 개념으로 넘어가는 흐름이다. 보안을 하려면 OS랑 네트워크 기초가 탄탄해야 한다는 걸 교육 구성 자체에서 느낄 수 있었다.

# 3. 리눅스 운영체제 기초

교육 비중이 가장 큰 파트였다. CentOS 설치부터 시작한다.

**다룬 내용:**
- CentOS 설치와 VMware 환경 구성
- 리눅스 종류와 소개 (배포판별 특징)
- 리눅스 구조와 쉘의 이해
- 기본 명령어, vim 에디터 사용법
- 네트워크 구성
- 파일과 디렉터리 구조
- 파일시스템 이해와 디스크 관리
- 사용자 관리 / 퍼미션 관리 / 프로세스 관리
- 패키지 관리 (yum, rpm)
- 로그 이해와 관리
- 리눅스 접근통제 기법

이미 학교 수업이랑 OverTheWire Bandit 풀면서 어느 정도 익숙한 부분도 있었는데, **접근통제 기법**이나 **로그 관리** 쪽은 실무적으로 정리가 됐다. 특히 SELinux, AppArmor 같은 MAC(Mandatory Access Control) 개념을 실습으로 만져본 게 좋았다.

# 4. 윈도우 운영체제 기초

리눅스에 비해 상대적으로 덜 만져봤던 파트라 집중했다.

**다룬 내용:**
- 윈도우 아키텍처 (커널 모드 / 유저 모드)
- 주요 프로세스와 서비스
- 레지스트리 구조와 이해
- 파일시스템 (NTFS, FAT 비교)
- 윈도우 계정 관리
- 공유 폴더 관리
- 서비스 관리 / 로컬 보안 정책 관리
- 이벤트 로그 관리
- 윈도우 분석 도구 소개

윈도우 커널 모드 드라이버 구조를 체계적으로 배운 건 이번이 처음이었다. HAL(Hardware Abstraction Layer)부터 상위/중간/하위 레벨 드라이버까지 계층을 정리하니까, 왜 윈도우에서 커널 익스플로잇이 까다로운지 감이 잡혔다. 레지스트리도 항상 regedit으로 단편적으로만 봤는데, HKLM/HKCU 등 하이브 키 전체 구조를 정리하니까 포렌식이나 악성코드 분석할 때 어디를 봐야 하는지가 명확해졌다.

# 5. 네트워크 기초

보안에서 제일 중요한 파트라고 생각한다.

**다룬 내용:**
- 네트워크 용어와 모델
- OSI 7계층 모델
- 스위치 개요와 종류
- ARP / 데이터링크 계층
- IP / ICMP / NAT
- TCP와 UDP
- 라우터와 라우팅 알고리즘
- 여러 대의 라우터를 활용한 망 구성
- 터널링의 이해와 구성 실습

학교에서 Wireshark로 패킷 분석하면서 TCP 3-way handshake 같은 건 알고 있었는데, **라우팅 알고리즘**이나 **터널링 구성**은 직접 실습으로 해본 게 이번이 처음이다. 특히 여러 대의 라우터를 가지고 망을 구성하는 실습이 인상적이었다. 나중에 DAH 해커톤에서 Docker로 네트워크 토폴로지를 구성할 때 이 지식이 바로 써먹어졌다.

# 6. 정보보안 기본요소 이해하기

마지막 파트는 보안 개론이다.

**다룬 내용:**
- 정보보호 산업 동향 및 중요성
- 사내 인프라 구성도로 보는 보안 직무와 역할
- 실무에서 사용되는 보안 용어들
- 정보보호의 목적 (기밀성 · 무결성 · 가용성)
- 정보보호의 위협과 위험
- 개인정보의 정의와 보호 필요성
- 개인정보 유노출 예방 및 조치사항
- 식별과 인증
- 권한부여 / 접근 통제 기술
- 물리보안 및 사회공학 기법

CIA 트라이어드야 기본 중의 기본인데, **사회공학 기법** 파트가 흥미로웠다. 기술적 취약점 못지않게 사람이 가장 큰 취약점이라는 걸 사례 중심으로 배웠다. 그리고 보안 직무별 역할을 인프라 구성도 기준으로 설명해주는 부분이 있었는데, 보안 컨설턴트·관제·침해사고 대응 등 진로를 고민할 때 참고가 됐다.

# 7. 수료 소감

80시간 동안 OS → 네트워크 → 보안 순서로 학습했다. 솔직히 완전 새로운 내용만 있었던 건 아니다. 학교에서 배운 게 겹치는 부분도 있었다. 근데 그게 오히려 좋았다. 흩어져 있던 지식을 **하나의 흐름으로 정리**할 수 있었다.

앞으로 심화과정도 도전할 생각이다.
